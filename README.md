# japan-trip-2026

טיול ליפן, 21/10 – 5/11/2026.

- [`index.html`](index.html): ה-web app, אפשר להתקין אותו על מסך הבית
- [`itinerary.md`](itinerary.md): המסלול המלא, יום אחרי יום, ברשימות רגילות
- [`source/JAPAN_2026.pdf`](source/JAPAN_2026.pdf): הגיליון המקורי

התכנון מהגיליון לא שונה. התוספות מסומנות כ״הצעה״.

## ה-web app

- עובד גם בלי אינטרנט, אחרי פתיחה ראשונה (`sw.js`)
- אפשר להוסיף למסך הבית (`manifest.webmanifest`)
- לפני הטיול מופיעה ספירה לאחור. בזמן הטיול האפליקציה קופצת ליום הנוכחי, לפי שעון יפן, ומסמנת אותו
- רשימת ההזמנות נשמרת במכשיר

אחרי שינוי במסלול, צריך להעלות את `VERSION` ב-`sw.js` כדי שהטלפונים יקבלו את הגרסה החדשה.

## פריסה ב-Vercel

אין שלב build. זה אתר סטטי.

1. ב-Vercel: **Add New → Project**, ולבחור את הריפו `japan-trip-2026`. אם הוא לא מופיע ברשימה, צריך לתת ל-Vercel גישה לריפו דרך GitHub.
2. Framework Preset: **Other**. להשאיר ריקים את Build Command ואת Output Directory.
3. **Deploy**.

מכאן, כל push לריפו מעדכן את האתר אוטומטית. הקבצים `source/`, `itinerary.md` ו-`README.md` לא עולים לאתר (ראו `.vercelignore`), והאתר מסומן כך שמנועי חיפוש לא יאנדקסו אותו.

## התקנה בטלפון

- **iPhone (Safari):** שיתוף ← הוסף למסך הבית
- **Android (Chrome):** תפריט ⋮ ← התקנת אפליקציה
